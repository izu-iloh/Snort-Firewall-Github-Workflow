# Screenshots

Save screenshots of your own lab execution in this folder. Use PNG where possible and capture only the relevant terminal/window area while keeping enough context to interpret the result.

## Suggested names

1. `01-virtualbox-network.png` — VM network adapter configuration.
2. `02-network-check.png` — assigned IP and connectivity test.
3. `03-mininet-r1.png` — Mininet running and R1 shell opened.
4. `04-snort-start.png` — Snort startup output.
5. `05-h10-listener.png` — H10 server listener verification.
6. `06-h5-request.png` — H5 request output.
7. `07-snort-alert.png` — alert line and its details.
8. `08-pcap-created.png` — PCAP file listed with non-zero size.
9. `09-firewall-rule.png` — `iptables` output showing the FORWARD-chain rule.
10. `10-blocked-request.png` — request result after the rule was added.
11. `11-cleanup.png` — Mininet exit and cleanup.

These are suggested evidence points based on the source lab; omit or rename any that do not match your actual workflow. Add a short caption to the documentation for each image. Never create fake terminal screenshots or edit output to make a step appear successful.
