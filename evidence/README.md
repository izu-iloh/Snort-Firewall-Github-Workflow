# Evidence

This folder is for supporting evidence that is safe and appropriate to publish, such as redacted text excerpts or a short evidence index.

Suggested file:
- `evidence-index.md` — list each screenshot/log excerpt and what it demonstrates.

Do not commit PCAP files by default. Captures may contain sensitive information and are ignored by `.gitignore`. Review them locally and share only if authorized and sanitized. Never add passwords, credentials, private keys, or sensitive personal information.
