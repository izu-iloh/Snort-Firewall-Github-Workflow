# Documentation

Use these files to document the lab without inventing results:

- `lab-overview.md` — purpose, objectives, and environment.
- `procedure-and-observations.md` — step-by-step log of what you actually did.
- `questions-and-findings.md` — answer the questions listed in the course PDF using your own evidence.

Keep the original course terminology where possible. If a step fails, document the error and troubleshooting attempted rather than marking it successful.
